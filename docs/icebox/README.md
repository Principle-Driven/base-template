# Icebox

Each unscheduled idea has one file named `<slug>.md`.
[AGENTS.md](../../AGENTS.md#icebox) defines the workflow.

An entry uses this structure:

```markdown
# Idea title

What the idea is and why it matters.

## Discussion

Decisions, alternatives, and their reasons.

## Open questions

Unusual questions from the discussion, if any.

## Sequencing

Known dependencies or agreed order, if any.
```
